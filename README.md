# Pistachoir: demo website

A five-page website for **Pistachoir**, a **fictional** gelato shop, built from scratch as a demo. Plain HTML, hand-written CSS, and one small vanilla JS file for the motion and the reservation form. No framework, no template.

Live: https://kardian.github.io/pistachoir-demo-site/

Everything here is invented: the shop, Teo, 9 Larkin Street, Port Ellery, (555) 017-4413 and hello@pistachoir.example. The reservation form only opens the visitor's own email app.
